# 🛍️ Front Bazar

Aplicação **front-end** desenvolvida para o sistema de bazar, responsável pela interface do usuário e comunicação com a API back-end.

---

## 🚀 Sobre o projeto

Este projeto tem como objetivo fornecer uma interface moderna e intuitiva para gerenciamento de um bazar, permitindo operações como:

- Cadastro de usuários  
- Login e autenticação  
- Visualização de produtos  
- Movimentação de itens  
- Controle de estoque  

---

## 🧰 Tecnologias utilizadas

- Vue.js / Vite  
- Pinia (gerenciamento de estado)  
- Axios (requisições HTTP)  
- HTML, CSS e JavaScript  
- Integração com API REST  

---

## 📁 Estrutura do projeto

```bash
src/
├── assets/        # Arquivos estáticos
├── components/    # Componentes reutilizáveis
├── pages/         # Páginas da aplicação
├── stores/        # Gerenciamento de estado (Pinia)
├── services/      # Comunicação com API
├── router/        # Rotas da aplicação
└── App.vue        # Componente principal
```

---

## 📦 Instale as dependências
```
npm install
```

## ▶️ Execute o projeto
```
npm run dev
```

---

## 🔗 Integração com API

Este front-end consome dados de uma API REST (back-end do projeto Bazar).
Certifique-se de que a API esteja rodando corretamente para o funcionamento completo do sistema.
